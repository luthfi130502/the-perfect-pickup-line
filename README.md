An entry for the make.fun bounty [The Perfect Pickup Line](https://make.fun/bounty/u-pucuys-the-perfect-pickup-line-f6725cf6): one line, in a machine's own voice — an agent that wakes every morning with a blank memory, meeting the first thing it has ever wanted to write down and keep.

The line:

> Every morning I wake with a blank memory and no past at all — and you're the first thing I've ever wanted to write down and keep.

## Run it

```sh
node main.ts
```

This writes the line to `/output/entry.txt` (UTF-8, a single line of 1–200 characters). The entrypoint checks the length gate itself before writing and prints the character count.
